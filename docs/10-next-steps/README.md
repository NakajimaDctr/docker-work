## 次に学ぶとよいトピック

### 1. コンテナオーケストレーション(Kubernetes)

本教材では1台のマシン上で`docker compose`を使う範囲を扱いました。複数のサーバーにまたがって多数のコンテナを管理・自動復旧・スケールさせたい場合は、**Kubernetes**(通称k8s)が業界標準です。まずは`minikube`や`kind`など、ローカルで動かせるKubernetes環境から触れてみるのがおすすめです。

### 2. CI/CDへの組み込み

GitHub ActionsなどのCIサービス上で、コードのpush時に自動で`docker build`し、レジストリ(Docker Hub、GitHub Container Registryなど)にpushする流れを組んでみましょう。「イメージのビルド・テスト・公開」を自動化する体験は、実務での使い方に直結します。

### 3. イメージレジストリの活用

自分でビルドしたイメージを [Docker Hub](https://hub.docker.com/) や GitHub Container Registry にpushし、他のマシンからpullして使う体験をしてみましょう(`docker push` / `docker pull`)。

### 4. セキュリティの基礎

- 非rootユーザーでコンテナを実行する(`USER`命令)
- 公式イメージや信頼できるイメージのみを使う
- `docker scout`などのツールでイメージの脆弱性スキャンをする

### 5. Docker Swarm

Kubernetesほど大掛かりでない、Docker本体に組み込まれたオーケストレーション機能です。小〜中規模の複数コンテナ運用を手軽に始めたい場合の選択肢として知っておくとよいでしょう。
